组织架构管理与用户注册接口设计

接口遵循现有 ApiResponse 包装结构：{ code, message, data }。

GET

获取注册选项

/api/auth/register/options

无需登录。返回注册页可选择的启用组织。

响应

{
  "code": "0",
  "message": "ok",
  "data": {
    "organizations": [
      {
        "id": 1,
        "orgCode": "DEFAULT",
        "orgName": "默认组织"
      }
    ]
  }
}
POST

用户注册

/api/auth/register

无需登录。注册成功后返回与登录接口一致的数据结构。

请求

{
  "username": "tester01",
  "displayName": "测试人员01",
  "password": "123456",
  "confirmPassword": "123456",
  "organizationId": 1
}

响应

{
  "code": "0",
  "message": "ok",
  "data": {
    "token": "xxx",
    "user": {
      "id": 10,
      "username": "tester01",
      "displayName": "测试人员01",
      "roles": ["TESTER"],
      "permissions": []
    }
  }
}

业务规则

字段规则
username必填，只允许英文或数字，不可重复。
displayName必填。
password必填，至少 6 位。
confirmPassword必须与密码一致。
organizationId必填，组织必须存在且启用。
GET

查询组织树

/api/organizations/tree

权限：MENU_ORGANIZATION

响应

{
  "code": "0",
  "message": "ok",
  "data": [
    {
      "id": 1,
      "parentId": null,
      "orgCode": "DEFAULT",
      "orgName": "默认组织",
      "leaderUserId": null,
      "leaderName": null,
      "sortOrder": 0,
      "status": "ACTIVE",
      "children": []
    }
  ]
}
POST

新增组织

/api/organizations

权限：MENU_ORGANIZATION

请求

新增组织只提交基础信息，不设置负责人；负责人在组织创建后通过编辑接口维护。

{
  "parentId": 1,
  "orgCode": "QA",
  "orgName": "测试部",
  "sortOrder": 10,
  "status": "ACTIVE"
}

响应

{
  "code": "0",
  "message": "ok",
  "data": {
    "id": 2,
    "parentId": 1,
    "orgCode": "QA",
    "orgName": "测试部",
    "leaderUserId": null,
    "leaderName": null,
    "sortOrder": 10,
    "status": "ACTIVE",
    "children": []
  }
}
PUT

编辑组织

权限：MENU_ORGANIZATION

请求

{
  "parentId": 1,
  "orgCode": "QA",
  "orgName": "测试部",
  "leaderUserId": 3,
  "sortOrder": 10,
  "status": "ACTIVE"
}

响应

{
  "code": "0",
  "message": "ok",
  "data": {
    "id": 2,
    "parentId": 1,
    "orgCode": "QA",
    "orgName": "测试部",
    "leaderUserId": 3,
    "leaderName": "张三",
    "sortOrder": 10,
    "status": "ACTIVE",
    "children": []
  }
}
